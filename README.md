# coupang-jiksong-plugin

쿠팡 물류동봉문서(거래명세서) PDF를 사방넷 발주등록(직송) 엑셀로 자동 변환하는 플러그인.

## 트리거
"직송 만들어줘", "직송으로 진행", "동봉문서 직송", "사방넷 직송" 등

## 입력
- 쿠팡 물류동봉문서 PDF (`물류동봉문서_YYYYMMDD_HHMMSS.pdf`)
- (이더컴퍼니 공산품일 때) 이더컴퍼니 재고조회 엑셀 — 바코드→상품코드 매핑용

## 출력
- `사방넷_{계정}_직송_{발주번호}.xlsx` (시트 `발주등록_sample`, 23컬럼)
- 배송방식=직송 / 발주 타입=쿠팡 - 파렛트출고 / 출고희망일=물류센터 도착예정일

## 매핑
- 뉴트리정(N): sku_master → 번들 SKU → 1개입 키워드(N00200xxx)
- 이더컴퍼니(E): 바코드 → 재고조회 상품코드

룰/마스터는 `skills/coupang-jiksong/scripts/mapping_rules.json`에서 갱신.
